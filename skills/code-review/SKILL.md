# Code Review Skill

This skill provides guidance for conducting thorough code reviews across all repositories in the organization.

## Instructions

When performing code reviews, follow these guidelines:

1. **Code Quality**
   - Check for code clarity and readability
   - Verify proper naming conventions are used
   - Ensure code follows DRY (Don't Repeat Yourself) principles
   - Look for potential performance issues

2. **Security**
   - Identify potential security vulnerabilities
   - Check for proper input validation and sanitization
   - Verify authentication and authorization implementations
   - Look for hardcoded secrets or sensitive information

3. **Testing**
   - Ensure adequate test coverage for new code
   - Verify tests are meaningful and test the right things
   - Check that edge cases are considered

4. **Documentation**
   - Verify code has appropriate comments where needed
   - Check that public APIs are documented
   - Ensure README is updated if functionality changes

5. **Best Practices**
   - Follow language-specific conventions
   - Use established patterns and practices
   - Ensure error handling is appropriate
   - Check for proper logging

## Usage

This skill will be automatically available to GitHub Copilot agents when reviewing code in any repository within the organization.
